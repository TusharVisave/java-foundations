# Java Foundations

A Java project focused on object-oriented programming, clean code,
unit testing, and Git/GitHub practices.

## Concepts Covered

- Abstraction
- Inheritance
- Encapsulation
- Polymorphism
- Input validation
- JUnit 5 testing
- Maven project management
- Git and GitHub

## Project Structure

The project contains a library item hierarchy:

- `LibraryItem` - Abstract base class
- `Book` - Represents a book
- `DVD` - Represents a DVD
- `Magazine` - Represents a magazine

## Testing

JUnit 5 is used to test:

- Item type and loan period
- Polymorphic behavior
- Invalid title validation
- Invalid item ID validation

## Technologies

- Java
- Maven
- JUnit 5
